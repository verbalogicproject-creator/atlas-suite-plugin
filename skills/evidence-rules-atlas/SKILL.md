# Evidence-Rules Atlas

Run governance before admission or retrieval changes.

1. Inspect ownership, license, consent, authority class, exact revision/content
   digest, freshness, sensitivity, retention, deletion, and intended use.
2. Keep `validated`, `built`, `observed`, `hypothesized`, and `open` distinct
   from source/document authority.
3. Preview the exact plan, then build only `evidence-rules` unless a requested
   preset visibly includes other flags.
4. Quarantine databases, compiled KBs, caches, logs, credentials, OAuth state,
   sessions, models, private bodies, ambiguous aliases, and unknown licenses.
5. Require a fresh digest-bound approval for live acquisition and a second
   staged-diff approval for active promotion.

Read `references/contract.md`. A passing receipt proves only its declared local
checks and never enables a connector, model, plugin, publication, or deployment.
