# Deterministic RAG KB v1

This curated release extends the preserved KG-RAG Specialist baseline with
source-ledgered observations relevant to deterministic owner workflows.

Read in this order:

1. `claims.json` for grounded claims, source standing, and limitations.
2. `platform-profiles.json` for local, plugin, connector, and model boundaries.
3. `candidate-recipes.json` for non-controlling future recipe candidates.
4. `adversarial-cases.json` for regression and lifecycle cases.
5. `harness-boot.receipt.json` for the blueprint-scoped release verdict.

The baseline 18-recipe cookbook and registry remain controlling. This KB does
not enable contextual-facet cosine retrieval, semantic retrieval, reranking,
generation, connectors, credentials, models, or protected effects.
