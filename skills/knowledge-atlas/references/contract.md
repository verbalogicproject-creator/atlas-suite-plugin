# Knowledge Atlas contract

- Flag: `knowledge`
- Facet: `claim_state` (`supported`, `contradicted`, `unresolved`, `tombstoned`)
- Default routes: lexical, graph-local, deterministic graph aggregates, RRF `k=60`
- Tie-break: stable ID
- Unknown evidence: abstain
- Safety/effect request: pre-retrieval refuse
- Generation input: `dkg-answer-plan/1.0` only
- Proof limit: governed evidence assembly; not source truth or effect authority
