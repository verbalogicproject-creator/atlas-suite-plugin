# Topology Atlas contract

- Flag: `topology`
- Facet: `edge_kind` (`imports`, `links`, `contains`, `depends-on`, `flows-to`)
- Every edge has a stable identity and resolving source/target endpoints
- Traversal depth, candidates, and context are bounded
- Global synthesis uses deterministic graph aggregates, never generated communities
- Proof limit: structural and impact context; runtime behavior needs separate evidence
